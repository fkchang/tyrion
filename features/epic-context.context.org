* Gotchas already paid for
- Org tags cannot contain hyphens (Emacs 29.4 tag class: alnum, `_`, `@`, `#`, `%`); `:s1-2:` parses as title text with no tags. Map story slugs with `slug.tr('-', '_')` before passing --tag/--tags. orgkit does not translate.
- Agent worktrees branch from origin/main, so the wiki is usually absent in the worktree; one messages-reading-layer builder wrote Learnings to its worktree copy and they were lost at merge. Every read/write in this epic goes through the main-checkout absolute path.
- orgkit exit 3 = mutation refused (stale sha, ambiguous target, lock held) and leaves every byte unchanged; exit 2 = usage. Surface orgkit's stderr verbatim; do not paraphrase it.
- Store#add_note metadata: is bound RAW: pass JSON.dump(...), never a Hash.
- Do not confuse epics.context_md (the DB SNAPSHOT of the file, refreshed after every write) with the file. The file is the source of truth; the DB copy exists so drift/epic show/prime work without touching disk.
- The web UI (web/) is not in scope; nothing there needs to change for this epic.
